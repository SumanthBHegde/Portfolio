## The problem

Vision LLMs can read handwritten math, but a one-off script that posts an image
to a model is not a system. It has no auth, no rate limiting, no record of what
was decided or why, and no structure to its output. For grading, where the
result carries weight, that does not cut it.

## What I built

Auto Grader is that same capability rebuilt as a production-shaped REST API.

- Vision-LLM grading of handwritten math through OpenRouter.
- Structured output: the model's reading is coerced into LaTeX and then JSON, so
  results are machine usable instead of prose.
- Security up front: HMAC-signed requests, API-key auth and rate limiting.
- An async task queue and audit logging that record every request and decision.
- Tested, and shipped in Docker so it is easy to run.

## How it turned out

It behaves like real infrastructure: authenticated, rate limited, auditable and
reproducible. This is my most production-shaped project, and the one that best
shows how I think about building an API rather than just calling a model.
